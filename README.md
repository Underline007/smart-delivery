# Smart Delivery

Ứng dụng quản lý cửa hàng, đơn hàng, kho (theo biến thể) và khách hàng, với 3 vai trò Admin · Chủ cửa hàng · Shipper; hỗ trợ shipper sắp xếp tuyến giao với Google Maps; xuất file Excel để tạo đơn hàng loạt trên ViettelPost. Thiết kế ưu tiên điện thoại (PWA), toàn bộ hạ tầng miễn phí.

- Kế hoạch phát triển chi tiết: [docs/PLAN.md](docs/PLAN.md)

Trạng thái: có bản nháp code giai đoạn 0–1, **chưa được duyệt** (xem [docs/PLAN.md mục 13](docs/PLAN.md#13-tiến-độ-thực-hiện)). App chưa chạy được.
